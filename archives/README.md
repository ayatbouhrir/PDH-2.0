# Archives conservées

- `references/` : copies algorithmiques antérieures et tests associés, hors du chemin d'import applicatif.
- `legacy/frontend/RunHistoryPanel.svelte` : ancien panneau sans appelant dans l'application initiale.
- `saved-files/` : fichiers `.save`, conservés sans modification.
- `system-files/` : fichiers `.DS_Store`, conservés pour la traçabilité.
- `generated/` : compilations SvelteKit/Vite et bytecode antérieurs aux déplacements.
- `logs/` : journaux antérieurs du frontend.
- `empty-directories/` : ancienne arborescence Python vidée par les déplacements.
- `regenerated-runtime/` : originaux de fichiers éphémères remplacés pendant les essais.

Ces fichiers sont historiques. Les chemins qu'ils contiennent ne sont pas des
instructions de lancement actuelles. Leurs anciens chemins figurent dans
`docs/migration/files.csv` et leurs empreintes originales dans la sauvegarde privée.
